# Publication source selection

This file documents packaging, not a new mathematical verification.

The selection contains 241 copied source/data files, including 130 Lean files and 38 Python files.
The filtered ledger has 113 machine entries, of which 44 are Lean entries. 102 entries are directly named by the manuscript graph or Lean sources; the remainder are referenced by retained programs or their evidence records.

## Reproduction

From the repository root:

```sh
python -m pip install -r requirements.txt
python research_ideas/probes/fixed_price/manuscript/supplement/verify.py
python research_ideas/probes/fixed_price/manuscript/first_layer_repair_20260921.py --run
python research_ideas/probes/fixed_price/manuscript/checks/first_layer_20260921/max_convexity_exact.py
python research_ideas/probes/fixed_price/manuscript/checks/first_layer_repair_20260921/physical_conditions.py
```

The Lean project retains its original pinned configuration:

```sh
cd research_ideas/probes/fixed_price/lean
lake exe cache get
lake build FixedPrice
```

## Portability and scope

The only source adaptation is in `hz_certify/ledger.py`: its machine-specific absolute ledger path is replaced by `Path(__file__).resolve().parents[1] / 'proof_factgraph' / 'ledger.toml'`. The workspace original is unchanged.

- Python >= 3.11 is required for tomllib. requirements.txt lists the packages used by the portable replay commands and imported helpers.
- The supported local replay is manuscript/first_layer_repair_20260921.py --run. It AST-loads the original mathematical functions and reads the filtered ledger. It writes two local receipt JSON files and does not edit the ledger or graph.
- manuscript/supplement/verify.py is unchanged and replays the finite witnesses and stored interval partitions; --fast skips its two interval-cover replays.
- The historical first_layer.py, first_layer_register_20260913.py, and first_layer_20260921.py main programs need unpublished manuscript TeX for source-location or byte-hash metadata. Their original source is retained; the repair driver reuses their mathematical functions without that metadata dependency.
- Some original constructors consult the ledger and return immediately when a receipt already exists. This is original lookup-first behavior, not a fresh replay. Use supplement/verify.py or the repair driver for reproduction.
- The legacy multiunit_screen.py module is included because exact_witness.py and continuum_to_finite.py import it. Its optional Gurobi search modes require gurobipy and a license; no published replay command uses those modes. Saved floating inputs are construction data, not universal proof evidence.
- cvxpy supports hz_certify.certificates' optional certificate-search functions; threadpoolctl is used by a retained legacy construction helper. They are included in requirements.txt even though the saved-certificate replay does not require a new optimization search.
- continuous_switching.py is retained only as the Reference helper imported by step_dual_components.py. Its numerical evaluations and step_dual_components.py's relaxed-energy output are discovery calculations, not machine proof credentials.
- Original source references and stored checksums are historical provenance. This packaging script adds no new content hashes, proof credentials, or verification gate.

## Omitted material

- The full manuscript TeX/PDF and its other build outputs; only the formalization supplement and paper.aux for its cross-references are selected.
- Unrelated research projects, discovery branches, source-paper PDFs, private prompts, agent conversations, and Rethlas proof-audit logs.
- Lean .lake caches, downloaded dependencies, junction targets, Python environments, optional Gurobi installation/license files, and generated bytecode.
- The full shared proof ledger; only fixed-price machine entries cited by the graph, Lean sources, and retained check programs are exported.
